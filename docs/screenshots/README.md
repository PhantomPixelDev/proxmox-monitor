# Screenshots

Every PNG here is generated by `scripts/capture_screenshots.py`, never cropped by hand.

```bash
python scripts/capture_screenshots.py --mock          # fake data, no Proxmox needed
python scripts/capture_screenshots.py                 # docs/live_health.json, else the live API
python scripts/capture_screenshots.py --theme light   # light palette
```

The script grabs each widget straight to a pixmap at 2x, so nothing appears on screen and the
PNGs stay sharp on HiDPI displays. It runs on the normal desktop platform on purpose: the Qt
offscreen plugin has no font database on Windows and renders every glyph as a tofu box.

| File | Tab | Rendered size |
| --- | --- | --- |
| `dashboard.png` | Overview — cluster and node metrics | 468 x 620 |
| `nodes.png` | Nodes — metrics, shell, web UI | 468 x 620 |
| `vms.png` | VMs — power and console per card | 468 x 880 |
| `containers.png` | LXC containers | 468 x 861 |
| `storage.png` | Storage — usage and free space | 468 x 626 |
| `search.png` | VMs filtered by a search term | 468 x 620 |
| `settings.png` | Settings dialog | 540 x 836 |

Notes:

- The settings capture uses a hardcoded demo cluster (`proxmox.lan`, `pve-home`), never your saved
  settings, so a real host or token id can never end up in a published image.
- `--mock` data lives in `mock_health()` in the capture script. Edit it there if a shot needs
  different guests.
- Keep each PNG under about 300 KB.
