🚀 How to use — 3 easy steps

Download → Install → Add your Proxmox → See your servers.

1️⃣

Download & run

Pick your download above. Install or just unzip and double-click.

2️⃣

Add your Proxmox

Find the tray icon → Right-click → Settings → Add Cluster. Enter your host your.server:8006 and API token.

3️⃣

See your servers

Done! Your nodes, VMs and storage appear live. Click Open Proxmox to jump to the web UI.

💡 API token tip: In Proxmox go to Datacenter → Access → API Tokens → Add. Create widget@pve!monitor, copy the secret once, paste as PVEAPIToken=widget@pve!monitor=secret in the app.

🛠️ Troubleshooting — 3 quick fixes

  • 🔴 Shows OFFLINE right after adding? Check host, port and token for typos. Try opening https://your.server:8006 in your browser first.
  • 🔒 Start/Stop says Forbidden (403)? Your token needs VM power permission. Add VM.PowerMgmt for that token in Proxmox → Permissions.
  • 🔍 Can't find the tray icon? On Windows check the hidden icons arrow ▲ near the clock. On Mac look in the top menu bar. Still missing? Close and reopen the app.
